# SRM Credit Engine

Plataforma de cessão de crédito multimoedas (BRL/USD) para precificação e liquidação de recebíveis com precisão decimal e segurança transacional.

> Documentação completa (arquitetura, como rodar, decisões) será adicionada ao longo do desenvolvimento.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `backend/` | API REST — Java 21, Spring Boot 4, PostgreSQL |
| `frontend/` | SPA do operador — React, Vite, TypeScript |
| `docs/` | Contrato da API, ADRs, diagramas C4 e ER |
